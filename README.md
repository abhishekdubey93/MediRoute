# MediRoute

MediRoute is a smart emergency response mobile app that helps users get instant first-aid guidance, locate nearby hospitals, and contact emergency services quickly.

## 🚑 Features

- Emergency first-aid guidance
- One-click ambulance call (108)
- Nearby hospitals using Google Maps
- User profile with emergency contact
- Firebase Authentication (Login/Register)
- Text-to-Speech emergency instructions

---

## 🛠 Tech Stack

- Android (Kotlin)
- Firebase Authentication
- Firebase Realtime Database
- Google Maps API
